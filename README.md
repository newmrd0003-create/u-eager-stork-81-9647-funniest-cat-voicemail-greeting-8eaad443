## Entry

> Hi, you've reached Mr. Whiskers. I'm napping on your keyboard. Leave a message after the meow. I'll ignore it.

110 characters, one line.

## Why this angle

The field has one other entry so far, and the brief rewards a greeting that is unmistakably a cat's voicemail, funny, full of character, specific to cats, and good spoken aloud. This entry does all five in one breath: a named cat (Mr. Whiskers) answers his own phone, the joke is a cat-specific habit (napping on the keyboard), the voicemail format is instantly recognisable ("Hi, you've reached...", "Leave a message after the meow"), and the punchline lands last — he will ignore the message anyway. Deadpan, cat-voiced, and built to be read out loud.

## How to run

```bash
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`). Validates first: single line, 1–120 characters.
